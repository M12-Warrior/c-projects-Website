# Legal policies — print / PDF copies

These are **archive copies** of the live Privacy Policy and Terms of Service for your `01-Legal-Formation` folder and a paper file.

| File | What it is |
|------|------------|
| `Privacy-Policy-print.html` | Privacy Policy (print-ready) |
| `Terms-of-Service-print.html` | Terms of Service + refunds (print-ready) |

Live pages (always current online):
- https://mile12warrior.com/privacy  
- https://mile12warrior.com/terms  

## Save as PDF (downloadable for your vault)

1. Double-click `Privacy-Policy-print.html` (opens in your browser).
2. Click **Print / Save as PDF** (or press `Ctrl+P`).
3. Printer: **Microsoft Print to PDF**.
4. Save as:  
   `Mile12Warrior-Business\01-Legal-Formation\2026-Privacy-Policy-live-site.pdf`
5. Repeat for `Terms-of-Service-print.html` →  
   `2026-Terms-of-Service-live-site.pdf`

## Physical paper copy

Open each PDF → **Print** on your HP printer → file in your official binder.

## After you update the website policies later

From the Website project folder run:

```powershell
node scripts/build-legal-print.js
```

Then save new PDFs again (add the new date in the filename).
